Положи сюда mp3-файлы с такими именами:

track-1.mp3
track-2.mp3
track-3.mp3
track-4.mp3

Плеер на сайте сам их подхватит. Если каких-то файлов не будет —
плеер тихо пропустит их и покажет следующий трек, ничего не сломается.

Если треков будет больше или меньше 4 — открой index.html,
найди в конце файла блок:

const TRACKS = [
  { title: 'Track 1', artist: 'Dream Visuals', src: 'tracks/track-1.mp3' },
  ...
];

и добавь/убери строки под свои файлы (можно поменять title/artist на реальные названия).
